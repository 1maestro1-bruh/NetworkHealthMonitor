## 📌 Описание проекта

Проект представляет собой распределенный программный комплекс для централизованного тестирования, сбора телеметрии и анализа стабильности сетевых сервисов. Система выполняет непрерывный мониторинг узлов по протоколам **HTTP** и **TCP**, рассчитывает время отклика (RTT), фиксирует сетевые сбои и аномалии, а также предоставляет REST API для визуализации метрик в реальном времени.

### Основные возможности ядра (Backend Engine):
* **Многопоточный асинхронный мониторинг:** фоновый опрос сервисов через `BackgroundService` и `PeriodicTimer` без блокировки основного потока.
* **Поддержка протоколов:** HTTP/HTTPS (проверка статус-кодов, заголовков) и чистый TCP (проверка установления соединения и сокетов).
* **Автоматическое определение состояний (Health State Machine):**
  * `ONLINE` — узел функционирует штатно, отклик в пределах нормы;
  * `WARNING` — узел отвечает, но время отклика превышает заданный порог (`LatencyThresholdMs`);
  * `OFFLINE` — узел недоступен (Connection Refused, Timeout, HTTP 5xx).
* **Хранение телеметрии:** локальная реляционная СУБД SQLite для записи временных рядов (Time-series) и журнала инцидентов.
* **REST API:** выдача агрегированной статистики KPI, детальной истории для графиков и CRUD-операций с узлами.

## 🛠 Технологический стек

* **Платформа:** .NET 8 (C# 12)
* **Архитектура:** Клиент-серверная (3-звенная: Mock-узлы $\to$ Сервер сбора $\to$ WPF-клиент)
* **База данных:** SQLite 3 (ORM: Entity Framework Core 8)
* **Сетевой стек:** `HttpClientFactory` (HTTP REST), `System.Net.Sockets` (TCP Sockets)
* **Сериализация:** JSON (`System.Text.Json`)
* **Клиентский интерфейс (в разработке):** WPF (.NET 8), паттерн MVVM (`CommunityToolkit.Mvvm`), Fluent Design (`Wpf.Ui`), графики `LiveCharts2`.
